Printing and reporting

Printing a visual

C# 
public static void PrintElement(FrameworkElement element, string description)
{
    var dialog = new PrintDialog();
    if (dialog.ShowDialog() != true) return;

    // Fit the element to the printable area before printing.
    var capabilities = dialog.PrintQueue.GetPrintCapabilities(dialog.PrintTicket);
    var area = new Size(capabilities.PageImageableArea!.ExtentWidth,
                        capabilities.PageImageableArea.ExtentHeight);

    double scale = Math.Min(area.Width  / element.ActualWidth,
                            area.Height / element.ActualHeight);

    var original = element.LayoutTransform;
    element.LayoutTransform = new ScaleTransform(scale, scale);
    element.Measure(area);
    element.Arrange(new Rect(
        new Point(capabilities.PageImageableArea.OriginWidth,
                  capabilities.PageImageableArea.OriginHeight), area));

    dialog.PrintVisual(element, description);

    element.LayoutTransform = original;
    element.Measure(new Size(element.ActualWidth, element.ActualHeight));
}

Good enough for "print this chart". Not good enough for anything multi-page.

Paginated printing with a FlowDocument

C# 
public static void PrintDocument(FlowDocument doc, string description)
{
    var dialog = new PrintDialog();
    if (dialog.ShowDialog() != true) return;

    // The document must be sized to the page before pagination.
    doc.PageHeight  = dialog.PrintableAreaHeight;
    doc.PageWidth   = dialog.PrintableAreaWidth;
    doc.PagePadding = new Thickness(48);
    doc.ColumnGap   = 0;
    doc.ColumnWidth = dialog.PrintableAreaWidth;   // single column

    IDocumentPaginatorSource source = doc;
    dialog.PrintDocument(source.DocumentPaginator, description);
}

Headers, footers and page numbers

WPF gives you no page furniture. You add it by wrapping the paginator:

C# 
public sealed class HeaderFooterPaginator(
    DocumentPaginator inner, string title, Thickness margin) : DocumentPaginator
{
    public override DocumentPage GetPage(int pageNumber)
    {
        DocumentPage page = inner.GetPage(pageNumber);

        var container = new ContainerVisual();
        container.Children.Add(page.Visual);

        var chrome = new DrawingVisual();
        using (DrawingContext dc = chrome.RenderOpen())
        {
            double dpi = VisualTreeHelper.GetDpi(chrome).PixelsPerDip;
            var face = new Typeface("Segoe UI");

            var header = new FormattedText(title, CultureInfo.CurrentUICulture,
                FlowDirection.LeftToRight, face, 9, Brushes.Gray, dpi);
            dc.DrawText(header, new Point(margin.Left, margin.Top / 2));

            var footer = new FormattedText(
                $"Page {pageNumber + 1} of {inner.PageCount}", CultureInfo.CurrentUICulture,
                FlowDirection.LeftToRight, face, 9, Brushes.Gray, dpi);
            dc.DrawText(footer, new Point(
                PageSize.Width - margin.Right - footer.Width,
                PageSize.Height - margin.Bottom / 2));
        }
        container.Children.Add(chrome);

        return new DocumentPage(container, PageSize,
                                page.BleedBox, page.ContentBox);
    }

    public override bool IsPageCountValid => inner.IsPageCountValid;
    public override int PageCount => inner.PageCount;
    public override IDocumentPaginatorSource Source => inner.Source;

    public override Size PageSize
    {
        get => inner.PageSize;
        set => inner.PageSize = value;
    }
}

inner.PageCount is only accurate once pagination has completed — call inner.ComputePageCount() first, or check IsPageCountValid.

Print preview

C# 
// Write an XPS document to a temp file and show it in a DocumentViewer.
public static void ShowPreview(DocumentPaginator paginator, Window owner)
{
    string path = Path.Combine(Path.GetTempPath(), $"preview-{Guid.NewGuid():N}.xps");

    using (var xps = new XpsDocument(path, FileAccess.ReadWrite))
    {
        XpsDocument.CreateXpsDocumentWriter(xps).Write(paginator);

        var viewer = new DocumentViewer { Document = xps.GetFixedDocumentSequence() };
        new Window { Content = viewer, Owner = owner, Width = 900, Height = 1100 }
            .ShowDialog();
    }

    File.Delete(path);
}

Requires a reference to ReachFramework and System.Printing, both of which come with UseWPF.

Choosing a reporting approach

NeedApproach
Print what's on screenPrintDialog.PrintVisual
Multi-page documents from dataFlowDocument built in code + a wrapping paginator
Pixel-exact layout (invoices, labels)FixedDocument, or generate a PDF with QuestPDF
Users design their own reportsA commercial designer, or export to Excel with ClosedXML
PDF outputQuestPDF — fluent, cross-platform, no XPS round-trip. The XPS-to-PDF path on Windows is lossy and awkward.

Silent printing and printer selection

C# 
using var server = new LocalPrintServer();

PrintQueue queue = server.GetPrintQueues()
    .FirstOrDefault(q => q.FullName.Contains("Zebra", StringComparison.OrdinalIgnoreCase))
    ?? server.DefaultPrintQueue;

var ticket = queue.DefaultPrintTicket.Clone();
ticket.PageOrientation = PageOrientation.Landscape;
ticket.CopyCount = 2;
ticket.PageMediaSize = new PageMediaSize(PageMediaSizeName.ISOA4);

var writer = PrintQueue.CreateXpsDocumentWriter(queue);
writer.Write(paginator, ticket);        // no dialog
