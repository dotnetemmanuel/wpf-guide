Thirty-eight parts

Read straight through, or jump to whatever is currently blocking you. Parts 1–20 are the framework itself; 21–34 are the corners you reach for when a real application demands them; 35–38 are history, migration and practice.

HOW TO READ THIS BOOK

Every part is written in layers. If WPF is new to you, start with the In plain terms boxes, which explain each idea and the problem it solves, then read the main text and finish with the Recap. Sections marked DEEPER can wait for a second pass. If you already know WPF, skip the boxes: the main text keeps every precise rule, and the deeper sections are written for you.
